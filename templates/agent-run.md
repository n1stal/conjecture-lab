# One bounded research pass

Read one target from the lab and reproduce its baseline. Literature-check the exact variant. Try one concrete mathematical approach: (1) build a counterexample family, (2) derive an all-size lemma, or (3) find a flaw in a proposed proof. Start with a tractable special case and distinguish a heuristic from an exact result. Use exact arithmetic and retain diagnostics. Log unsuccessful attempts as well as positive ones.

Return the statement in checked form and one of: a directly checkable witness with independent verification; a proof draft with explicit gaps; a completed Lean theorem for the exact stated scope; or a negative result with precise bounds. Do not treat examples as proof or model confidence as verification. Do not use new credentials, pay for an API, publish, or run indefinitely. If delegated in an explicitly authorized paid environment, stay within its declared budget.
